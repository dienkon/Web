# docs

Thư mục này dùng để tách tài liệu chi tiết cho từng project con trong repo `MyWeb`.

## Cách tổ chức khuyến nghị

```text
docs/
├── README.md
├── template-project.md
├── chemdex.md
├── meet.md
├── quan-ly-lich-hoc.md
└── ...
```

## Khi nào cần tạo file docs riêng

Tạo một file docs riêng khi project:

- có nhiều trang hoặc nhiều tính năng,
- có backend / build step riêng,
- cần mô tả luồng sử dụng rõ hơn,
- hoặc có nhiều người cùng đọc / cùng phát triển.

## Mẫu nhanh cho một docs project

```md
# Tên project

## Giới thiệu
...

## Mục tiêu
...

## Tính năng chính
- ...

## Cấu trúc thư mục
...

## Cách chạy
...

## Ghi chú
...
```

## Danh mục docs

- `template-project.md`: Mẫu để copy cho project mới.
