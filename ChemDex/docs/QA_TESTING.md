# Checklist kiểm thử

## 1. Kiểm thử cơ bản

- [ ] Trang chủ tải được.
- [ ] Bảng tuần hoàn hiển thị đủ layout.
- [ ] Click vào nguyên tố có dữ liệu mở được chi tiết.
- [ ] Các nguyên tố chưa có dữ liệu vẫn hiển thị đúng placeholder.
- [ ] Chatbot widget xuất hiện.

## 2. Kiểm thử dữ liệu

- [ ] `manifest.json` load được.
- [ ] File JSON nguyên tố load đúng.
- [ ] `categories.json` map đúng màu.
- [ ] Nội dung chi tiết không bị lỗi field thiếu.

## 3. Kiểm thử điều hướng

- [ ] Điều hướng giữa các trang hoạt động.
- [ ] URL nguyên tố có thể mở trực tiếp.
- [ ] Nút quay lại / đóng panel hoạt động.
- [ ] Sidebar / filter mở và đóng đúng.

## 4. Kiểm thử media

- [ ] Ảnh hiển thị đúng tỉ lệ.
- [ ] Video nhúng hoạt động.
- [ ] Mô hình 3D có thể xoay.
- [ ] Widget tinh thể hiển thị không crash.

## 5. Kiểm thử tương thích

- [ ] Chrome / Edge / Firefox.
- [ ] Màn hình desktop.
- [ ] Màn hình tablet.
- [ ] Màn hình mobile.

## 6. Kiểm thử hiệu năng

- [ ] Trang không treo khi render dữ liệu.
- [ ] Scroll vẫn mượt.
- [ ] Không có lỗi JS console nghiêm trọng.
- [ ] Dữ liệu lớn không làm đóng băng giao diện.

## 7. Kiểm thử nội dung

- [ ] Chính tả tiếng Việt thống nhất.
- [ ] Tên nguyên tố đồng nhất ở mọi nơi.
- [ ] Đơn vị đo có ghi rõ.
- [ ] Tránh lặp nội dung không cần thiết.
