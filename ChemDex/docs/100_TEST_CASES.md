## ⚙️ Scoring Mechanism

Điểm matching tùy thuộc vào độ tương tự:

| Loại Match                | Điểm  | Ví dụ                       |
| ------------------------- | ----- | --------------------------- |
| **Giống hệt (exact)**     | 1.0   | "tóm tắt" = "tóm tắt"       |
| **Chứa trong (contains)** | 0.85  | "tóm tắt nhanh" ⊃ "tóm tắt" |
| **Rất gần (0.7-0.84)**    | 0.75  | "tóm tắttt" ≈ "tóm tắt"     |
| **Gần (0.5-0.69)**        | 0.60  | "thông tin" ≈ "tóm tắt"     |
| **Không phù hợp**         | < 0.5 | ❌ Không dùng               |

## 📝 Ghi chú

- **Threshold**: 0.5 (nếu score ≥ 0.5 thì trả lời)

- **Logic**:保toàn vẹn - chỉ match để tìm category, template vẫn từ JSON
- **Performance**: O(n\*m) với n = categories, m = keywords (nhanh vì tập hợp nhỏ)
