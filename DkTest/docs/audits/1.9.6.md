3. **Fix triệt để lỗi Arena (Đấu Trường) gây tốn Firestore reads (`src/services/arenaService.ts`, `src/pages/student/ArenaLobby.tsx`, `src/pages/student/ArenaRoom.tsx`, `firestore.rules`, `database.rules.json`, `scripts/cleanup-legacy-arena-rooms.ts`)**:

     2. Phòng kết thúc (`status: "finished"`) hoặc khi người chơi thoát bằng nút Back / đóng tab / bấm `"Quay lại Sảnh Đấu Trường"` từ Podium không bị xóa khỏi Firestore, làm tích tụ hàng trăm tài liệu rác (`301` reads khi truy vấn/mở collection `/arena_rooms` trong Firestore Console).
     3. `firestore.rules` không có rule cho `arena_rooms` (khi rule cũ trên production còn mở sẽ tích tụ tài liệu rác; khi deploy rule mới sẽ chặn ngầm).

   - **Biện pháp khắc phục**:

     - Bổ sung `onDisconnect` dọn người chơi khi mất kết nối ở phòng chờ, kiểm tra TTL 2 giờ (`ARENA_ROOM_TTL_MS`), đồng bộ đầy đủ `status: "finished"` & `winnerUid` lên RTDB, tự xóa `arena_room_codes/{roomCode}` khi trận đấu kết thúc, và dọn phòng sạch khi người cuối cùng rời Podium.
     - Khóa cứng `match /arena_rooms/{roomId} { allow read, write: if false; }` trong `firestore.rules` và bổ sung rule RTDB cho `arena_rooms/$roomId` và `arena_room_codes/$roomCode` trong `database.rules.json` (không mở `.read` toàn cục trên root `arena_rooms`).
     - Thêm script dọn các tài liệu `/arena_rooms` tồn đọng trên Firestore (`scripts/cleanup-legacy-arena-rooms.ts`, hỗ trợ dry-run và `--execute`).

## Firestore

- **Read Budget**:
  - **Arena (Đấu Trường)**: **0 Firestore reads / 0 Firestore writes** khi tạo phòng, vào phòng bằng mã, lắng nghe realtime, cập nhật từng câu, kết thúc trận và rời phòng (vận hành hoàn toàn trên RTDB). Đề mặc định `toan12_standard_01` và kho `SIEUGIOI_QUESTIONS` nạp cục bộ **0 Firestore reads**; chỉ khi chủ phòng tạo phòng bằng mã đề Firestore tùy chỉnh mới tra 1 query `limit(1)` hoặc 1 doc `getDoc` lúc tạo phòng.
  - **Kiểm tra cập nhật App**: Gọi `/api/app-download?format=json` (Vercel/GitHub API), **0 Firestore reads**.
  - **Khóa học (`CourseDetail`, `CoursesList`)**: Giữ nguyên cache `courses/{courseId}` và `courses:published`; tách tab `Bài kiểm tra` không làm tăng reads; prefetch link tài liệu chỉ chạy cho các bài đã có quyền trong chủ đề đang mở khi học sinh bấm sang tab `Tài liệu` và cache trong state (`authorizedLessonsCache`) để không đọc lặp.

## Security

- **Khóa cứng `arena_rooms` trên Firestore**: `firestore.rules` chặn tuyệt đối mọi thao tác đọc/ghi vào `/arena_rooms/{roomId}` (`allow read, write: if false;`), ngăn client cũ hoặc script ngoài tạo rác / đọc collection này trên Firestore.
- **Bảo vệ RTDB Arena**: `database.rules.json` chỉ cho phép đọc/ghi theo khóa cụ thể `arena_rooms/$roomId` và `arena_room_codes/$roomCode`, không bật `.read: true` ở nhánh gốc `arena_rooms` để tránh quét toàn bộ danh sách phòng.
- **Bảo mật Khóa học**: URL video và URL tài liệu trả phí tuyệt đối không xuất hiện trong `lessonOutline` công khai; chỉ được nạp qua `getAuthorizedCourseLesson` sau khi kiểm tra quyền ở Firestore rules / API.
- **Kiểm tra cập nhật App**: Chỉ điều hướng tới URL APK từ cấu hình `ANDROID_APK_URL` hoặc GitHub Release chính thức `dienkon/Web/releases`, giữ nguyên toàn bộ cơ chế xác thực và offline token hiện có.

## Deployment

- Toàn bộ mã nguồn thay đổi nằm cục bộ trên nhánh `main`:
  1. Cần triển khai cả **`firestore.rules`** và **`database.rules.json`** lên Firebase (`firebase deploy --only firestore:rules,database`) để khóa `arena_rooms` trên Firestore và mở rule RTDB cho `arena_rooms` / `arena_room_codes` trên production.
  2. Chạy dọn 301 tài liệu `/arena_rooms` tồn đọng trên Firestore production bằng script `npx tsx scripts/cleanup-legacy-arena-rooms.ts` (dry-run trước) rồi `npx tsx scripts/cleanup-legacy-arena-rooms.ts --execute`.
  3. Cần deploy lại web/API lên Vercel (bao gồm `api/app-download.ts` đã có CORS) và push nhánh `main` để GitHub Actions build & phát hành APK `DkTEST-1.9.6-debug.apk` lên GitHub Releases.

## Risks

- Trong khoảng thời gian chuyển tiếp (trước khi `database.rules.json` được deploy lên Firebase production), nếu DB RTDB production chưa cập nhật rule mới cho `arena_rooms`, tính năng Arena sẽ tạm fallback local memory trên máy người dùng cho đến khi deploy `database.rules.json`.
- Kiểm tra tự động cập nhật App trên điện thoại thật phụ thuộc vào việc GitHub Release `dktest-v1.9.6` có sẵn asset `.apk` và API `/api/app-download?format=json` trên production đã được deploy bản mới có header CORS.
- Chưa kiểm thử cài đặt file APK `1.9.6` trực tiếp trên điện thoại Android vật lý (chỉ kiểm tra build APK, unit tests, emulator rules và Playwright offline E2E với Capacitor bridge mock).
