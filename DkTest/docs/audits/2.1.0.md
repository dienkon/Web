## 1. Scope & Objectives

1. **Exhaustive Deep Link Scanning & Sub-Exam Unpacking**:
   - Crawl both post feeds and static pages across educational repositories, raise internal `folderTree_ft` / multi-link extraction limits (`subFiles <= 600` per post), unpack individually named exams from multi-file compilation packs into standalone searchable entries (`unpackNamedSubExams`), and automatically pair Answer-Key files (`Đáp án / Lời giải`) onto their matching Exam files (`a: answerUrl`).
2. **Multi-Source Expansion Surpassing `>= 20,000+` Authentic Documents**:
   - Discover and integrate open-API educational exam repositories (`toanmath.com`, `giaoandethitienganh.info`, `hoctai.vn`, `tailieudethi.vn`, `dethithu.net`, plus full uncapped `mathvn.com`, `nganhangdethi.org`, `tailieuonthi.edu.vn`, and `tailieuonthi.org`), prioritizing **Grade 12**, **National High School Graduation (THPT QG)**, **School / Department Mock Exams (Đề Trường - Sở)**, **Quality Surveys (KSCL)**, **Semester Exams (GK1, HK1, GK2, HK2)**, and **Competency / Thinking Assessments (HSA, TSA, V-ACT, SPT)**.
3. **Multi-Tiered Color-Coded Visual Hierarchy (`DocumentLibraryPage.tsx` & `DocumentDetailPage.tsx`)**:
   - Replace flat white-on-white surfaces with a calm, multi-tiered color hierarchy across Light & Dark mode so students can scan 28,000+ documents effortlessly, and add a 1-click **Priority Exam Focus Bar** (`topicFilter`).

## 2. Findings & Root Causes Addressed

1. **Unpacked Multi-File Packs Previously Hidden Behind Parent Cards**:
   - Thousands of individual provincial/school mock exams inside `folderTree_ft` compilation posts were only accessible after opening a parent pack. By introducing `unpackNamedSubExams` with normalized stem matching (`normalizePairStem`), `30,934` standalone named exams were extracted and paired with their answer keys while preserving all `1,202` parent packs (`480` with nested internal folder trees) in `public/data/document-library-packs.json`.
2. **Visual Contrast Fatigue on Large Document Grids ("màu trắng không khí")**:
   - Previously, `DocumentLibraryPage.tsx` placed white cards (`bg-white`) on an untinted page background with uniform neutral borders, making folder spaces, source roots, and subject cards blend together. Introducing a cool-slate workspace canvas (`Tier 0`), deep gradient Hero & tinted Space Sections (`Tier 1`), subject/source-accented card ribbons & surfaces (`Tier 2`), and a structured Filter Control Deck (`Tier 3`) creates immediate visual landmarks.
3. **Client Memory & Parse Overhead at `28,000` Items**:
   - Expanding compact prefixes (`tm:`, `mf:`, `eduu:`, `ga:`, `ht:`, `mv:`), stripping default properties (`g: "grade_12"`, `c: "exam_test"`, `f: "pdf"`, default `src`), caching normalized taxonomy strings (`normalizedTaxonomyCache`), and pre-indexing `_searchKey` + `_topicKey` once inside `seedBundlePromise` keep full-catalog search and facet counting under `15ms`.

## 5. Security Boundaries

- **Zero Paid URL Leakage**: All 28,000 public seed items are 100% free open educational links; paid Admin/Community uploads continue to strip `fileUrl`, `answerUrl`, `videoUrl`, and `subFiles` on `/api/documents/catalog` until server-verified entitlement in `library_entitlements`.
- **SSRF-Hardened PDF Proxy (`/api/documents/pdf-proxy`)**: External PDFs (such as `https://toanmath.com/toanmath-pdf/*.pdf`) stream safely through the existing HTTPS-only, DNS/private-IP-validated, content-type/size-bounded proxy without weakening any server check or Firestore rule (`firestore.rules` untouched).
- **Ethical Open-API Harvesting Only**: All 7 sources were harvested strictly through public Blogger JSON feeds and WordPress REST APIs without bypassing any authentication, paywall, or anti-bot gate.

## 7. Remaining Risks & Mitigations

- **Static Seed Payload Size (`~11.3 MB` uncompressed / `~1.7 MB` gzipped)**:
  - *Risk*: Slower initial load on uncached 3G connections when opening `/student/documents` for the first time.
  - *Mitigation*: Compact prefix encoding + default-field stripping cut raw JSON size by ~45%, Vite/CDN serves `/data/document-library-seed.json` with HTTP gzip/brotli compression and browser cache reuse, and `document-library-packs.json` (`~3.4 MB` raw) is lazy-loaded only when inspecting or batch-downloading a multi-file pack.
- **External Third-Party Link Rot**:
  - *Risk*: Individual external Google Drive or `toanmath-pdf` files may be removed by upstream authors over time.
  - *Mitigation*: Every document preserves its `sourcePostUrl` (`pu`) and Admin overrides (`library_seed_overrides`) allow hiding or updating any broken seed link without redeploying.
