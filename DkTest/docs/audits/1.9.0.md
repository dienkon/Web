## Firestore

### Read Budget & Indexes

- **Homepage & Android online/offline**: Không tăng số lượng query trang chủ; mobile Android vẫn giữ ngân sách tối đa 5 đề mới chỉnh sửa lúc mở tab Online và đọc 0 doc Firestore ở tab Offline.
- **Lịch sử chi tiêu toàn server (`wallet_transactions`)**:
  - Truy vấn theo composite index mới trong `firestore.indexes.json`: `(type ASC, createdAt DESC)` với `limit = 5` và cursor `startAfter(createdAt)`.
  - Page đầu theo filter được cache in-memory trên server TTL ngắn (`15s`) và bị vô hiệu hóa khi phát sinh giao dịch trừ tiền mới (`unlockExam`, `unlockCourse`, `unlockCourseLesson`).
  - Lưu ý kỹ thuật khi chưa triển khai composite index lên production: ở chế độ fallback REST (`all_spending` gồm nhiều `type` hoặc thiếu index), server có thể đọc tối đa `100` bản ghi `wallet_transactions` gần nhất trước khi lọc và cắt về `5` mục (được ghi nhận trong output test `tests/walletFirestoreOptimization.test.ts`). Do đó cần `firebase deploy --only firestore:indexes` trước khi dùng production đông dữ liệu.
- **Khóa học (`courses` & `course_entitlements`)**:
  - Catalogue `getPublishedCourses`: 1 query `where("status", "==", "published"), orderBy("updatedAt", "desc"), limit(24)` + client cache 120s. Thêm composite index `(status ASC, updatedAt DESC)`.
  - Trang chi tiết khóa học `CourseDetail`: đọc 1 document `courses/{courseId}` (chứa sẵn `lessonOutline` sanitized không có `videoUrl`), gọi API `/api/courses/:courseId/access` kiểm tra quyền trên `course_entitlements` (index `uid ASC, courseId ASC`), và chỉ đọc 1 doc `courses/{courseId}/lessons/{lessonId}` khi học sinh mở xem bài được phép.

## Security

- **Tách dữ liệu công khai & nội dung video trả phí (`firestore.rules`)**:
  - Document gốc `/courses/{courseId}` chỉ lưu metadata + `lessonOutline` (đã loại bỏ `videoUrl` và `materials`); rule ghi của Admin cấm trường `lessons` lồng trong document gốc (`!('lessons' in request.resource.data)`).
  - Subcollection `/courses/{courseId}/lessons/{lessonId}` yêu cầu `isAuthenticated() && mayReadCourseLesson(courseId, lessonId)`: cho phép đọc nếu là Admin, hoặc khóa học miễn phí, hoặc `accessType == 'free'`, hoặc `accessType == 'inherit_first_n'` với `order < freePreviewCount`, hoặc tồn tại `course_entitlements/{uid}_{courseId}__{lessonId}` active, hoặc tồn tại `course_entitlements/{uid}_{courseId}` active (khi `unlockFullPolicy == 'unlock_all_videos'` hoặc `includedInCourseUnlock != false`).
  - `/course_entitlements/{entId}` chỉ cho Admin hoặc chính chủ `uid` đọc; học sinh không được tự ghi/sửa (chỉ server hoặc Admin ghi).
  - Giao dịch mua khóa học, mua lẻ video và áp dụng Voucher (`course_unlock`) chạy atomic trên backend với `idempotencyKey`, kiểm tra `salesEnabled`, số dư Ví và điều kiện Voucher trên server.
  - Xem trước đề gốc & lời giải trên `OfflineExamSetup` giữ ranh giới hiển thị trước giờ thi; `TakingExam` tiếp tục chặn mở modal xem lời giải trong lúc làm bài.

## Deployment

### Triển khai thực tế vs Code đã cài đặt

- Các thay đổi trong `src/`, `server/`, `firestore.rules`, `firestore.indexes.json` đã hoàn thiện trong mã nguồn local nhưng **chưa tự động deploy lên Firebase/Vercel production** và **chưa kiểm thử trên thiết bị Android thật**.
- Trước khi sử dụng trên production, quản trị viên cần thực hiện theo thứ tự:
  1. Deploy Firestore Rules & Composite Indexes mới (`wallet_transactions(type, createdAt)`, `courses(status, updatedAt)`, `course_entitlements(uid, courseId)`):
     ```bash
     firebase deploy --only firestore:rules,firestore:indexes
     ```
  2. Build và deploy ứng dụng Web + Serverless API (`/api/admin/*`, `/api/wallet/*`, `/api/courses/*` với rewrite trong `vercel.json`) lên Vercel / máy chủ Node.
  3. Build APK `1.9.0` (`versionCode=6`) và cài đặt trên thiết bị thử nghiệm để kiểm tra UI offline/online, App Links và luồng thanh toán Ví với dữ liệu thật.

## Risks

- Nếu chưa chạy `firebase deploy --only firestore:indexes` lên production, truy vấn lịch sử chi tiêu toàn server hoặc lọc khóa học sẽ rơi về nhánh fallback tốn nhiều lượt đọc hơn hoặc cần sắp xếp in-memory.
- Tài nguyên video upload trực tiếp qua Cloudinary dùng unsigned preset hiện tại (`uploadFileToCloudinary`) phụ thuộc giới hạn dung lượng file của gói Cloudinary; các bài giảng dài nên dùng link YouTube / MP4 HLS / Google Drive.
- Dữ liệu khóa học chỉ mang tính năng online (`<OnlineOnly>`), không tải gói video offline vào APK để tránh phình dung lượng bộ nhớ máy.
- Bản APK build local dùng debug signing key và các bài kiểm thử Playwright chạy trên Chromium với fixture + Capacitor bridge mock cục bộ, không thay thế kiểm thử trên điện thoại thật.
