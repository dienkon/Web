# Audit DkTEST 1.9.4

Date: 2026-11-18. Android versionCode: 10. Previous: 1.9.3 / code 9.

## Scope

1. **Fix lỗi hiển thị frame video bị lệch & cắt điều khiển trên Mobile (`DkCourseVideoPlayer.tsx`, `CourseDetail.tsx`, `BrandLogo.tsx`, `StudentLayout.tsx`)**:
   - **Nguyên nhân**: Ở màn hình điện thoại (`~360px` rộng), hộp `aspect-video` chỉ cao khoảng `190px`, làm giao diện nhúng Google Drive (`/preview?rm=minimal`) không đủ chiều cao tối thiểu, đẩy thanh tua lên cạnh trên và cắt mất nửa thanh nút điều khiển bên dưới. Ngoài ra cột Grid chính của `CourseDetail` thiếu `min-w-0 w-full` và badge `"Thi Trực Tuyến"` ở header `StudentLayout` quá rộng khiến cạnh phải bị tràn trên điện thoại nhỏ.
   - **Khắc phục**:
     - Cấp `h-[268px] sm:h-auto sm:aspect-video` cho iframe Google Drive / nhúng ngoài trên mobile và giữ `h-full` khi fullscreen; ép `[&>div]:!w-full [&>div]:!h-full [&>iframe]:!w-full [&>iframe]:!h-full` cho container `YT.Player`.
     - Bổ sung `min-w-0 w-full` cho 2 cột Grid trong `CourseDetail.tsx` (`#course-player-stage`) và thêm `hideBadgeOnMobile` trên `BrandLogo.tsx` khi đặt ở `<header>` của `StudentLayout.tsx`.

2. **Tự động phát ngay video sau khi user mở khóa (`CourseDetail.tsx`, `DkCourseVideoPlayer.tsx`)**:
   - Thêm prop `autoPlay?: boolean` trên `DkCourseVideoPlayer` cho cả HTML5 `<video>`, YouTube `YT.Player` và tham số `autoplay=1` với iframe.
   - Trong `handleConfirmUnlock` (`CourseDetail.tsx`): cập nhật lạc quan quyền truy cập (`access`), chọn ngay bài vừa mở khóa (`unlockTarget.lesson` hoặc bài đang xem nếu mở trọn khóa), bung đúng cây Nhóm/Chương/Chuyên đề, gắn `?lesson=`, cuộn mượt lên trình phát và đặt `autoPlayLessonId` để tự phát video lập tức.

3. **Tích hợp tải phần mềm Android APK & phiên bản vào phần hỏi mở App (`OpenInAppBanner.tsx`, `StudentLayout.tsx`, `appLinks.ts`, `api/app-download.ts`, `.github/workflows/dktest-android-release.yml`)**:
   - Hiển thị huy hiệu phiên bản `v1.9.4 (Code 10)` và nút **`Tải App v1.9.4 (APK)`** ngay bên cạnh nút **`Mở trong app`** trong `OpenInAppBanner.tsx` (kèm tùy chọn PWA `beforeinstallprompt` và hướng dẫn nhanh khi bắt đầu tải), cũng như trong menu `StudentLayout.tsx` (Desktop Sidebar & Mobile Drawer/Bottom Sheet).
   - Tạo endpoint `GET /api/app-download` (`api/app-download.ts`, `src/services/server/appDownload.ts`, `server.ts`) ưu tiên đọc `ANDROID_APK_URL` / GitHub Releases API (`dienkon/Web`) để chuyển hướng tải file `.apk` trực tiếp, hoặc trả về trang tải dự phòng gọn đẹp nếu bản release CI chưa build xong.
   - Thêm workflow `.github/workflows/dktest-android-release.yml` tự động build `DkTEST-<version>-debug.apk` + `.sha256` và đính kèm lên GitHub Releases mỗi khi push `main` (vẫn giữ nguyên quy tắc không commit `.apk` vào Git).

## Security

- Không lưu trữ file nhị phân `.apk` vào repository Git hoặc Firebase Hosting tĩnh; URL tải qua `/api/app-download` chỉ đọc từ biến môi trường cấu hình hoặc API công khai chính chủ `https://api.github.com/repos/dienkon/Web/releases`.
- Vẫn giữ nguyên kiểm chứng App Links (`appRouteFromUrl`, `intent://`) và toàn bộ quy tắc thanh toán khóa học trên server & `firestore.rules`.

## Deployment & Prerequisites

- **Trạng thái triển khai**: Toàn bộ mã nguồn, cấu hình `/api/app-download` và workflow `.github/workflows/dktest-android-release.yml` đã hoàn tất trên nhánh `main` và được đẩy lên `origin/main` cùng commit phát hành; bản deploy sản xuất trên Vercel và job GitHub Actions build/đính kèm `DkTEST-1.9.4-debug.apk` lên GitHub Releases chạy bất đồng bộ sau khi push.
- **Tùy chọn cấu hình**: Có thể đặt biến môi trường `ANDROID_APK_URL` trên Vercel nếu muốn trỏ `/api/app-download` sang một liên kết `.apk` cố định thay vì tự tra cứu GitHub Releases API (`dienkon/Web`).

## Risks & Limitations

- Một số trình duyệt di động có thể chặn tự động phát video có tiếng nếu phiên bấm nút thanh toán kết thúc sau một lời gọi mạng dài; nếu trình duyệt từ chối `play()`, nút Play trung tâm vẫn sẵn sàng để bấm 1 chạm phát ngay và giao diện không gặp lỗi.
- Trước khi GitHub Actions build xong lần đầu sau khi push `dktest-v1.9.4`, nút tải `/api/app-download` sẽ rơi về bản APK gần nhất hoặc trang hướng dẫn GitHub Releases cho đến khi workflow hoàn tất.
- **Chữ ký APK & App Links**: APK build bởi CI GitHub Actions dùng debug keystore tạm của runner CI (khác với SHA-256 debug keystore cục bộ đang khai báo trong `public/android-assetlinks.json`), nên auto-verify Android App Links cho bản APK từ CI sẽ chưa khớp trừ khi dùng chung keystore ký cố định trên CI và cập nhật `public/android-assetlinks.json` (bấm mở trực tiếp hoặc dùng web vẫn hoạt động bình thường).
